Code of Conduct defined

Communication:
-We will use Whatsapp for communication during this group project. 
-Important updates should be replied to within 24 hours. 

Meetings:
-All members should attend the weekly lab on Thursdays to keep up with the project. If unable to attend organising a different time to meet is suggested.
-All members attend code reviews as they are mandatory for the grading of the project. 

Development:
-We will follow GitFlow workflow (including ‘master’, ‘develop’, and ‘release’ branches).
-Code must be reviewed by Pull Requests before merging into ‘develop’.
-Comment messages must be clear for easy understanding of other members.

Accountability and Contribution:
-Tasks will be tracked using GitHub Project Kanban board.
-If a team member is struggling with tasks, they must notify the team for help.
-Individual contribution percentages need to be submitted at review stages to make the grading more accurate.

Conflict Resolution:
-Disagreements must be handled during meetings with all team members present.
-Lack of contribution will be addressed and reported through individual contribution charts.
